# Historical Planning Archive

This directory is a minimal pointer for superseded planning material. The
original Workbench masterplan was removed from `main` during the 2026-05-25
archive trim; it is no longer the active roadmap or public documentation
surface.

Current planning and release status lives in:

- `ROADMAP.md`
- `docs/roadmap.md`
- `docs/public-production-release-evidence-ledger.md`
- `docs/dependency-and-package-policy.md`
- `docs/releases/`

Template migration reference pages remain in `docs/` for public navigation, but
they are marked historical/current-state reference material:

- `docs/vpw_template_execution_sequence.md`
- `docs/full_stack_fastapi_template_migration.md`

Archived planning files should be retained only when they are still necessary
for active docs or tests. They should not be treated as current scope,
acceptance criteria, or release commitments. Superseded audit drafts and
intermediate implementation plans should stay out of the repository unless a
maintainer explicitly asks for a durable record.

When historical planning claims are promoted back into public docs, verify them
against `docs/documentation-evidence-matrix.md`, current source, and current
tests first.
